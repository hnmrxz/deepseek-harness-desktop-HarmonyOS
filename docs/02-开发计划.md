# 开发计划

> 执行入口：给开发代理/AI 使用。优先修复用户可感知问题与安全边界，再做扩展能力；没有设备时先完成 L0/L1，可验证项不得停滞。

## P8｜稳定性、导航与安全收口

1. 修正返回优先级组合态：所有可见顶层浮层/预览优先于下面页面层级。
2. 统一返回、显式关闭、Sheet dismiss、系统返回的状态归一化。
3. 补齐“进入/退出页面不丢上下文”的状态契约。
4. 修复页面覆盖/裁切风险：安全区域、软键盘、Sheet 可视高度、多栏最小宽度、操作区让步。
5. **系统提示词安全收口**：`system/message`、`internal=true`、未知事件不得进入对话/搜索/复制/引用/通知/导出；诊断日志默认脱敏。
6. **API 错误统一建模**：区分连接断开、Host 拒绝、模型请求失败、自动重试、已排队、输入参数错误；避免全部落成“操作失败”。
7. 清理 API 24 兼容问题、构建依赖闭包与已知技术债。

**出口**：返回专项 fixture 全绿；安全 fixture 全绿；API 错误状态机全绿；任意组合态只有唯一返回动作；新克隆可重复构建。

## P9｜UI 完成度与四形态收口

以 `docs/08-UI与返回交互审计.md` 和 `docs/09-安全与API错误呈现审计.md` 为强制验收基线。

### 手机
单栏、底部主要操作、抽屉、键盘避让、单手热区、贴底、返回优先级，以及错误提示不得遮挡 Composer。

### 折叠屏
闭合/展开/半折时保持会话、选择、滚动与草稿上下文；布局变化不重建业务状态；中缝不得截断关键内容。

### 平板
导航 + 内容 + 条件详情；减少 Sheet；列表与详情保持稳定层级；分屏后重新计算可用宽度。

### 2in1
窗口缩放、多窗口、hover、右键、快捷键、拖拽、触控统一语义；宽度下降时必须隐藏/让步，不允许裁切。

**出口**：同一功能四种形态均有稳定入口；无假按钮、无“点击无反应”、无上下文丢失、无关键操作被遮挡。

## P10｜信息架构、视觉系统与错误体验

1. 收口首页/工作区/会话/设置的信息层级。
2. 清理重复标题、过度卡片、空白区域、临时控件与不一致间距。
3. 统一主/次/危险/取消操作层级。
4. 统一 Sheet、Dialog、Toast、通知与系统返回语义。
5. 所有视觉裸值继续向 Tokens/HarmonyTheme/NativePrimitives 收敛。
6. 错误提示必须回答：发生了什么、是否生效、下一步做什么；恢复后及时清理 transient error。

## P11｜运行时治理

核心版本、插件、升级迁移、备份恢复、损坏检测继续遵循 `staging → validate → activate → observe → rollback`。

## P12｜性能与发布

覆盖冷启动、长会话、事件增量、滚动、图片、内存、网络抖动、后台恢复，以及签名/AGC/升级回滚；发布前增加“提示词不泄露 + 错误不泄露敏感信息”的安全回归。

## AI 开发纪律

```text
目标：一句用户可感知结果
事实：上游协议/当前代码/已验证设备事实
改动：dshcompat / appstate / platform / hostruntime / entry / tools
状态：唯一状态源 + 明确修改者
导航：进入、返回、关闭、系统返回都写清楚
UI：入口 / 空态 / loading / success / error / retry
安全：普通会话路径永远不能看到 internal/system/unknown 原始内容
错误：连接 / Host / 模型 / 重试 / 队列 / 输入必须有不同用户语义
验证：纯模型 fixture + 接线门禁 + 设备项
禁止：顺手增加第二套状态、第二套导航、第二套错误文案体系
```

## 优先级

P0 核心闭环/错误返回/敏感内容隔离；P1 日常操作与状态反馈；P1.5 多形态体验；P2 治理发布；P3 装饰。不得以 P2/P3 掩盖 P0/P1。

# 当前状态与缺口

## 已完成底座

- 本地 dsh Host + 原生 ArkUI Client 定位已确定。
- `phone` / `tablet` / `2in1` 已写入模块设备类型，多窗口基础架构存在。
- `Tokens / HarmonyTheme / NativePrimitives` 形成 UI 设计链；`Breakpoints / LayoutController / NavigationController` 形成布局/导航决策链。

- SDK 口径为 `6.1.1(24)`；ABI 为 `arm64-v8a` + `x86_64`。

## 当前最高优先级缺口

### P0 返回与层级（P8-1 已收口，剩余项如下）

- **已完成**：`decideBack()` 的次序按“最上层可见内容优先”重排；“预览是不是整页层”由
  `previewIsLayer()` 判定（单栏 = 工作区第 2 层；多栏并排栏不算层）；关预览同时把下钻退回文件树
  （`drillAfterPreviewClosed()`），并**经中枢** `closeFilePreview()` 清（视图那份只是镜像，只清镜像 = 假关闭）。
- **已完成**：返回、页头返回箭头、文件树返回箭头、诊断/连接页返回箭头共用 `Index.consumeBack()`；
  浮层复位只保留 `closeSheet()` 一处；除 `STACK_TO_MAIN` 外新增 `BACK_TO_LIST`（手机单栏：会话是“盖在列表上的一层”，
  返回列表**保留会话**）——修掉“第一次白按、第二次退出应用”。
- **已完成**：组合 fixture 从“顺路几条”升级为**全组合矩阵**（2304 种，表驱动独立对账）。
- **剩余**：多栏下“预览是右栏面板”时是否该吃返回键（取决于该面板此刻是否显示）——需真机确认，见 `docs/device-validation.md` D40。
- **剩余**：Sheet 的关闭原因区分（完成 / 取消 / 返回 / 系统关闭 / 外部状态变化）目前只有“复位”，没有把原因回传给调用方；
  编辑态未保存内容的取消/保存策略仍按“直接丢弃草稿”处理。

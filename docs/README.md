## 纪律

1. **D1 冻结后**，范围 / 目标 / 验收的变更必须走 D1 §12.3 的变更流程并升版本号，不允许静默偏离。
2. **D2 的每条事实必须标注来源**（代码 / 官方文档 / 实测 / 待实测）；标注「待实测」的条目在补齐证据前不得据以实现。
3. **D4 的每个 POC 必须有证据**；无证据的「通过」视为未通过；失败结论必须与通过结论同等留档。
4. 实施期与设计的偏差写进 `specs/`（as-built 记录），不改写历史文档。

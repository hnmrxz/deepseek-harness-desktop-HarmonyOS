## 当前决策

1. 产品是端侧原生 HDSH，不是 PC 远程遥控器。
2. Host 与 Node Runtime 随应用提供；UI 使用原生 ArkUI。
3. 目标设备为 phone / tablet / 2in1，折叠屏作为 phone/tablet 间的连续形态处理。
4. SDK 基线为 `6.1.1(24)`。
5. 先完成 P8–P12，再扩大低频功能范围。

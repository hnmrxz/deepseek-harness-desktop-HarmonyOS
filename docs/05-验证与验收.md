# 验证与验收

## 1. 验证分层

| 层级 | 环境 | 目标 |
|---|---|---|
| L0 | 本机 Node | 纯模型、协议投影、导航、布局、错误映射、返回 fixture、安全脱敏 fixture |
| L1 | DevEco CLI | ArkTS/CMake、静态检查、门禁、打包预检 |
| L2 | x86_64 模拟器 | 页面结构、输入、窗口、系统返回与大部分交互 |
| L3 | arm64 真机 | 触控、折叠、通知、后台、系统 API、性能 |
| L4 | 发布包 | 签名、安装、升级、回滚、AGC、安全发布检查 |

远程开发无设备时继续完成 L0/L1，不得修改代码掩盖 L2/L3 未验证事实。

## 2. UI 专项验收

每个主要页面都要覆盖：

- 首次进入 / 返回 / 再进入；
- 空态 / 加载 / 成功 / 失败 / 重试；
- 明确关闭 / 系统返回 / Sheet 下拉关闭；
- 当前有草稿、有选择项、有未完成任务时退出；
- 浮层与页面同时存在的组合态；
- 手机 / 折叠 / 平板 / 2in1 的布局与输入差异；
- 安全区域、软键盘、动态字体、长文本、操作区不被覆盖/裁切。

## 3. 返回专项 fixture

至少覆盖：

```text
抽屉 + 任意浮层
搜索 + 详情
选择器 + 二级页
详情覆盖 + 二级页
文件预览 + wsDrill > 0
文件预览 + 非工作区页签
会话详情 + 当前会话仍存在
根层 + 无任何覆盖
```

每个组合只允许一个 `BackAction`，并断言执行后相关状态全部归一化。

**落地情况（P8-1）**：上面这些组合已不再是“逐条列举”，而是升级为**全组合矩阵**——
`tools/check-layout-fixtures.mjs` 把阶梯按文档顺序写成**数据表**，对
`抽屉 × 四类编辑浮层 × 详情半模态 × 文件预览 × 会话整页 × 详情栏 × 二级页(3) × 下钻(3) × 页签(2)`
共 **2304 种组合**逐个比对 `decideBack()`，任何一条分支挪位置都会在某个组合上被抓住
（这是用**独立实现**对账 if 链，不是把实现抄一遍当期望）。

## 4. 安全专项 fixture

必须覆盖：

```text
system/message → 普通对话不可见
internal=true → 普通对话不可见
internal=true → 搜索结果不可见
internal=true → 不得复制/引用到草稿
未知事件 → 不得把原始 JSON 当用户正文
错误文本包含 token/cookie/Authorization → UI 与日志脱敏
通知 → 不得包含系统提示词、token、原始堆栈
诊断导出 → 仅白名单字段
```

安全测试不能只测 `ConversationAudience.HIDDEN`；必须测试实际出口（搜索、复制、引用、通知、导出、日志）。

## 5. API 错误专项回归

至少覆盖：

| 场景 | 用户状态 | 验收 |
|---|---|---|
| WebSocket/Host 断开 | 连接已断开 | 有重连入口，不伪装成模型错误 |
| Host 拒绝请求 | 请求未执行 | 展示人话原因 |
| 模型 API 错误 | 当前轮失败 | 只影响当前轮，不污染整个会话 |
| 自动重试 | 正在重试 | 显示次数/倒计时，不同时显示冲突 error 状态 |
| 已加入队列 | 已排队 | 不显示失败，不导致重复发送 |
| 参数/附件错误 | 输入未发送 | 保留可修正的输入 |
| 恢复成功 | 已恢复 | 清除 transient error，不重复弹出 |

## 6. 核心回归

Host 生命周期、连接/重连、会话、发送失败恢复、排队去重、模型重试、工具/命令/审批/目标/子代理、输入 token 替换、多窗口共享状态、插件/核心切换继续保持现有回归集。

## 7. 设备最小矩阵

手机：竖横屏、软键盘、深浅色、返回、后台恢复、长列表、错误提示位置。  
折叠：闭合/展开/半折、旋转、上下文连续、中缝遮挡检查。  
平板：主从、详情让步、附件/文件选择、分屏、三栏最小宽度。  
2in1：窗口缩放、hover、右键、快捷键、拖拽、多窗口、错误 banner 与操作区。

## 8. 发布门槛

所有既有门禁通过；返回专项 fixture、安全专项 fixture、API 错误专项 fixture 全绿；不得存在已知“按钮可点但无效果”“返回退错层”“视觉关闭但状态未清”“系统提示词可通过旁路出口读取”“错误提示覆盖输入区或泄露敏感字段”的问题；设备未验证项必须明确标记。

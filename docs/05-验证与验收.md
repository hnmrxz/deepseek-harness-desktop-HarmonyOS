# 验证与验收

## 1. 验证分层

| 层级 | 环境 | 目标 |
|---|---|---|
| L0 | 本机 Node | 纯模型、协议投影、导航、布局、错误映射、返回 fixture |
| L1 | DevEco CLI | ArkTS/CMake、静态检查、门禁、打包预检 |
| L2 | x86_64 模拟器 | 页面结构、输入、窗口、系统返回与大部分交互 |
| L3 | arm64 真机 | 触控、折叠、通知、后台、系统 API、性能 |
| L4 | 发布包 | 签名、安装、升级、回滚、AGC |

远程开发无设备时继续完成 L0/L1，不得修改代码掩盖 L2/L3 未验证事实。

## 2. UI 专项验收

每个主要页面都要覆盖：

- 首次进入 / 返回 / 再进入；
- 空态 / 加载 / 成功 / 失败 / 重试；
- 明确关闭 / 系统返回 / Sheet 下拉关闭；
- 当前有草稿、有选择项、有未完成任务时退出；
- 浮层与页面同时存在的组合态；
- 手机 / 折叠 / 平板 / 2in1 的布局与输入差异。

## 3. 返回专项 fixture

至少覆盖：

```text
抽屉 + 任意浮层
搜索 + 详情
选择器 + 二级页
详情覆盖 + 二级页
文件预览 + wsDrill > 0
文件预览 + 非工作区页签
会话详情 + 当前会话仍存在
根层 + 无任何覆盖
```

每个组合只允许一个 `BackAction`，并断言执行后相关状态全部归一化。

## 4. 核心回归

Host 生命周期、连接/重连、会话、发送失败恢复、排队去重、模型重试、工具/命令/审批/目标/子代理、输入 token 替换、多窗口共享状态、插件/核心切换继续保持现有回归集。

## 5. 设备最小矩阵

手机：竖横屏、软键盘、深浅色、返回、后台恢复、长列表。  
折叠：闭合/展开/半折、旋转、上下文连续。  
平板：主从、详情让步、附件/文件选择、分屏。  
2in1：窗口缩放、hover、右键、快捷键、拖拽、多窗口。

## 6. 发布门槛

所有既有门禁通过；返回专项 fixture 全绿；不得存在已知“按钮可点但无效果”“返回退错层”“视觉关闭但状态未清”的问题；设备未验证项必须明确标记。

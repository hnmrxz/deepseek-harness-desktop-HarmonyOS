# 产品与功能说明

## 1. 产品定位

HDSH 是 DeepSeek Harness 的 HarmonyOS 原生客户端与端侧运行载体。核心目标是让用户在 HarmonyOS 手机、折叠屏、平板、2in1 上连续完成“连接 → 选择工作区 → 发起任务 → 观察 Agent → 处理审批/提问 → 查看交付物 → 继续迭代”。

产品路线分两条（2026-09-20 v2 转向）：

- **PC / 平板 / 2in1 / 折叠展开**：以内嵌 Web 组件（ArkWeb）直接加载官方 Web UI——与官方**同一前端产物**，天然像素级一致；桌面语义（键鼠 / hover / 右键 / 快捷键 / 拖拽）完整生效。
- **手机 / 折叠闭合**：以克隆的 DSH Mobile 源码为唯一参照**逐屏原生复刻**其移动交互范式（含设计 token 移植）。

两条路线都要求保留上游语义、不制造“可点但无效”的假入口。

### 1.1 对标基线（2026-09-20 v2 修订）

| 形态 | 对标对象 | 对标口径 |
|---|---|---|
| 手机（含折叠闭合） | [DSH Mobile](https://github.com/sorsama/deepseek-harness-mobile)（sorsama 的 Android 原生 companion，Kotlin + Compose；克隆源码在 `.research/deepseek-harness-mobile`） | **源码级对照复刻**：以其为**唯一参照**逐屏原生复刻移动交互范式——回合流 / 顶栏 / 输入区 / 工具卡、抽屉式导航（左缘右滑出会话列表、右缘左滑出会话详情）、队列 dock（可编辑/移除/插入待发回合）、目标 dock、轨迹台账、Sheet 系列与连接/设置屏；并**移植其 `ui/theme/` 设计 token**（`appstate/ui/MobileTheme.ets`）作为手机链唯一视觉 token 源。**仍不对标其“远程遥控器”产品模型**——HDSH 是端侧自足运行，不依赖另一台机器。 |
| PC / 平板（含折叠展开、2in1） | **dsh 官方最新原版**（官方 Web UI；当前参考底档为仓库根 `v37.2.3-20260825.1-release.zip`） | **官方产物直载**：以 Web 组件直接加载端侧 dsh host 伺服的官方 Web UI（本机 `http://127.0.0.1:3120`；远程模式加载远程主机地址）——与官方**同一前端产物**，天然像素级一致，60+ 官方 client-ui 组件与键鼠 / hover / 右键 / 快捷键 / 拖拽等桌面语义全部生效。能力对等仍由 `docs/parity-matrix.md` 逐行登记。 |

上游版本升级时，官方 Web UI 随 core 更新**天然跟随**（Web 直载无需 UI 侧改动）；手机链以最新 DSH Mobile 源码重跑逐屏对照并更新矩阵，而不是沿用旧结论。

## 2. 用户任务

| 用户任务 | 结果 |
|---|---|
| 开始工作 | 选择或恢复工作区，查看最近会话 |
| 提问/执行 | Composer 支持文本、附件、`@` 引用、`/` 命令 |
| 观察执行 | 在对话与轨迹之间查看回答、工具、命令、子代理、目标、任务、错误 |
| 做安全决策 | 审批卡只暴露真实存在的上游动作；缺少关键事实时 fail-closed |
| 处理中断 | 重试、暂停/恢复目标、修改/清除目标、管理待发队列 |
| 管理环境 | Provider、模型、凭据、插件、核心版本、连接与主题 |
| 跨形态使用 | 手机单栏；折叠/平板双栏；2in1 多窗、键鼠、拖拽、快捷键 |

## 3. 功能范围

### P0：核心闭环

会话创建/恢复、消息发送与失败恢复、流式回答、会话轨迹、工作区关联、本地 Host 生命周期、网络断线恢复、待发队列、审批与提问。

### P1：生产力

附件、文件引用、斜杠命令、工具结果、命令结果、子代理、任务、目标、交付物、搜索与文件浏览、通知、窗口记忆。

### P1.5：HarmonyOS 体验层

系统 Sheet、系统符号、语义颜色/排版/间距、统一 NativePrimitives、断点与布局控制器、输入模态策略、无障碍与触控热区。

### P2：运行时治理

多核心版本并存、校验后激活、失败回滚、插件部署状态、升级迁移、备份恢复、诊断与日志导出。

### P3：发布能力

签名、AGC 预检、升级路径、发布包可重复构建、崩溃/异常观测与隐私说明。

## 4. 明确非目标

- 不把 WebView 当作通用主 UI——Web 直载仅用于 PC / 平板等桌面形态（加载官方同一前端产物）；手机形态坚持 DSH Mobile 源码对照的原生复刻。
- 不 fork DeepSeek Harness 的 agent 业务逻辑。
- 不修改上游安全围栏来扩大网络暴露面。
- 不为当前端侧无法可靠支持的能力制造“看起来可点但实际上无效”的按钮。
- 不把 PC 桌面布局缩小后直接用于手机。
- 不把“未在真机验证”写成“已完成”。

## 5. 功能完成定义

一个功能只有同时满足以下条件才可标记 DONE：

`Protocol` 协议入口明确；`State` 状态归属唯一；`Functional` 主路径可完成；`Interaction` 点击/手势有真实结果；`Responsive` 目标形态可用；`Accessibility` 可访问；`Validation` 有可重复验证方法；`Failure` 有失败与降级路径。

## 6. 体验优先级

优先保证：发送与恢复 > Agent 执行反馈 > 审批/提问 > 工作区与文件 > 会话管理 > 高级配置 > 装饰性视觉。

任何视觉优化不得以削弱上述核心闭环为代价。

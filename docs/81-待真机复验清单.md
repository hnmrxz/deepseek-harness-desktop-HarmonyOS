## 庚档：**PC 形态（WebShell 直载官方 UI）**——2026-09-21 模拟器已验，剩余两条

> 方法（可复现）：PC 侧起 0.1.6-alpha.2 核心（`node --jitless --expose-internals --experimental-sqlite hostcore/app/main.js`，`HDSH_CORE_DIR`/`HDSH_HOME`/`HDSH_SANDBOX_HOME`/`HDSH_PORT=3120`/`HDSH_PROFILE=ondevice`/`HDSH_IN_LOG=1`）→ `hdc rport tcp:3120 tcp:3120`（authority 保持 `127.0.0.1:3120` 才被信任栅栏接受）→ 2in1 模拟器 `aa start -a EntryAbility -b com.hnmrxz.hdsh --ps dshHost http://127.0.0.1:3120 --ps dshToken <token>`。这条路径**绕开**「x86_64 模拟器缺 libnode」（核心跑在 PC 上）。

| # | 项 | 怎么算通过 |
|---|---|---|
| 47 | **PC 形态直载官方 UI**（已修，模拟器 `PASS`） | 修前：宿主全程零浏览器 UA 请求 / 页面 `about:blank`。修后：宿主出现 ArkWeb UA + cookie 的 SPA 引导流量（`/assets/*.css`、`/api/settings/describe`、`/api/dynamicCordisRunner/*`、`/plugins/events`、`/manifest.webmanifest`），界面渲染官方多栏 UI（会话 / 工作区 / 设置 / 新建会话）。**真机复核判据同上**（`WEBSHELL` 旁路日志应出现 `loadUrl returned normally` → `empty-page preempt → retry load` → `pageEnd url=http://127.0.0.1:3120/`） |

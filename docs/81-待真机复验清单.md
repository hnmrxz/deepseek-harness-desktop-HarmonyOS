# 待真机复验清单（2026-09-17 无真机阶段的产物）

> **这份清单是给"下一次接上设备"的人用的**。它把 2026-09-17 无真机阶段改过的每一件事
> 按**验证成本**排成几档，并写明**怎么算通过**。
>
> **口径**：本轮改过但没在设备上复核的项，一律是 **`已修待验`**——不是"已完成"。
> 这份清单存在的意义就是**不让"改过了"被当成"验过了"**。

## 三、UI 对标官方口径（结论）

口径：**PC / 平板 / 2in1 与官方 1:1**（在能完整实现的功能范围内）；**手机端适应性优化，但图标与整体风格保持一致**。落地：`Index` 把 `LayoutMode` 发布到 `AppStorage('dshLayoutMode')`，组件用 `@StorageProp` 读——一处真值，不新增第二条判定链。

| 改动 | 生效范围 | 与官方对照 |
|---|---|---|
| 正文超长折行 + 「展开」 | **已撤销**（全形态都不折） | 官方不做正文折叠，用户已要求改回 |
| 过程条目平铺（不分组） | 全形态 | 官方过程时间线平铺、无分组头 ⇒ 1:1 |
| 工具卡折叠态一行 | 全形态 | 官方每个过程条目就是一行 ⇒ 1:1 |
| 设置页说明统一一行 | 全形态 | 官方"标签/一句说明 + 右侧控件" ⇒ 1:1 |
| 评价按钮（有帮助/没帮助） | 仅非单栏（手机隐藏） | 官方有评价入口；手机隐藏属适应性优化，PC/平板/2in1 1:1 保留 |
| 工具行短标签（`@` `/`）、不可切时隐藏权限 chip、模型 chip 收窄 120 | 仅单栏 | 官方是带文字的 chip ⇒ 其他端保持原样 |
| 去掉单栏底部标签栏（导航只走抽屉） | 仅 `OVERLAY`（单栏） | 官方手机也是抽屉 |
| 返回键打开抽屉而不是"工作区页面" | 仅单栏 | 侧栏本就是官方的工作区容器 |
| 去掉侧栏「工作区」导航席位 | 全形态 | 官方侧栏"工作区"是分组标题，不是导航项 ⇒ 1:1 |
| 空正文的助手行整行不画 | 全形态 | 官方没有"只有动作条"的空行 |

图标结论：图标名权威来源是 `sysResource.js` 的 `sys.symbol` 清单（7251 个符号）；`command`/`terminal`/`shield` **不在**清单里（照直觉写会得到空白按钮）；模型 chip 的 `⌄`（`chevron_down`）已全形态对齐；`@` 与 `/` 保持**文字**与官方记法一致（官方工具行根本没有这两个按钮，它们是本仓给手机加的可点入口）；"图标不按形态分叉"由门禁 `tools/check-icon-parity.mjs` 静态守着（红/绿均已验：塞入按形态分叉的 `sys.symbol` ⇒ 退出码 1 并指出行号）。

## 1. 信息架构

```
启动
 └─ 连接层（未配对 / 连接中 / 已连接）
     ├─ 待决（Pending）        ★ 移动端默认首屏（有待决时）
     ├─ 会话（Sessions）
     │   └─ 会话详情
     │       ├─ 轨迹（Chat）
     │       ├─ 详情栏（Details）：工具 / 子代理 / 交付物 / 目标 / 任务 / 计划
     │       └─ 输入区（Composer）
     ├─ 工作区（Workspaces）
     │   └─ 文件树 / 文件预览 / 交付物
     ├─ 设置（Settings）
     │   ├─ 通用（外观 / 通知 / 后台 / 语言）
     │   ├─ 模型（模型 / 推理强度 / 凭据状态 / 交互式授权）
     │   ├─ 插件（清单 / 市场）
     │   └─ 设备（Host 列表 / 配对 / 吊销）
     └─ 诊断（Diagnostics）：连接五项判定 / 协议日志 / 导出日志
```

**一级导航项**（三形态一致，呈现方式不同）：待决 · 会话 · 工作区 · 设置（诊断从设置进入，设备从设置进入）。

## 2. 三形态导航模型

| 形态 | 判定 | 导航 | 记忆 |
|---|---|---|---|
| **手机**（`sm`，宽 < 600vp） | 单栏栈式 | 一级列表 → 会话 → 详情 逐级下钻；系统手势/返回键逐级返回 | 记住上次会话；返回列表保留滚动位置 |
| **折叠屏（折叠态）** | 同手机 | 同手机 | 展开时自动进入双栏并落在同一会话 |
| **折叠屏（展开态）/ 平板竖屏**（`md`，600–840vp） | 双栏 | 左：一级导航（可收为图标条 56vp）；右：当前会话 | 展开/折叠切换不丢上下文、不重载数据 |
| **折叠屏（悬停态）/ 平板横屏 / 2in1**（`lg`/`xl`，≥ 840vp） | 三栏 | 左：导航；中：会话；右：详情（可收） | 详情栏宽度记忆；窗口大小记忆（2in1） |

### 2.1 让步链（空间不足时的收缩顺序）

```
详情栏收窄 → 详情栏关闭 → 导航栏收为图标条 → 导航栏抽屉化
```

- 让步只改**几何**，不改数据；重新变宽时**自行恢复**（不把 store 中的宽度当渲染真值）；
- 详情栏关闭后不保留占位；导航收为图标条后保留 56vp 控制条；
- 挤压重排期间**禁止滚动锁定**（避免读者视口被移动）。

### 2.2 断点实现约定

| 手段 | 用途 |
|---|---|
| 窗口宽度断点监听（`sm/md/lg/xl`）+ 折叠态/悬停态特征 | 顶层形态切换（导航模型） |
| `GridRow` / `GridCol` | 卡片网格、设置项、详情面板内部的栅格响应 |
| `SideBarContainer` | 双栏/三栏骨架 |
| `ContainerReader`（API 26 起） | 组件级断点：同一组件在窄容器（如分屏中的会话）内自适应，不受窗口宽度误导 |

> **硬规则**：顶层形态只用**窗口**断点；出现在可复用小部件内的自适应只用**容器**断点。混用会导致分屏/多窗场景破版。

## 3. 关键界面规格

### 3.1 会话列表项

| 元素 | 规格 |
|---|---|
| 标题 | 单行省略；无标题时用首条用户消息前 20 字 |
| 副信息 | 工作区名 · 最后活动相对时间（<1 分钟「刚刚」，<1 小时「N 分钟前」，<24 小时「N 小时前」，否则日期） |
| 状态 | `运行中`（脉冲点）/ `待审核 N`（高亮徽标）/ `空闲` / `失败`（红点） |
| 未读 | 圆点 + 数量（>99 显示 `99+`） |
| 操作 | 长按：重命名 / 导出 / 删除；侧滑：删除（二次确认） |
| 性能 | 1000 项列表滑动 ≥ 55 fps；首屏 ≤ 300 ms |

### 3.2 轨迹消息

| 类型 | 呈现 |
|---|---|
| 用户消息 | 右侧气泡（或全宽卡片，随形态）；显示时间；可复制/引用/重发 |
| assistant 消息 | 全宽 Markdown；流式时尾部光标动效；显示耗时与模型名（次要字号） |
| 思考/reasoning | 默认折叠为一行「思考中… / 已思考 N 秒」，可展开 |
| 工具调用 | 独立卡片（见 3.3） |
| 子代理 | 嵌套卡片：名称 / 状态 / 最后一条 assistant 摘要 / 可展开其轨迹 |
| 交付物 | 文件卡片：名称 / 类型图标 / 大小 / 预览 / 保存 / 分享 |
| 计划 / 目标 / 任务（jobs） | 折叠区块，含状态与进度；目标显示当前轮次进度 |
| 错误 | 红色左边框 + 错误码 + 「重试 / 查看诊断」 |

**渲染规则**：Markdown 全部支持（含表格、任务列表、引用）；代码块带语言标签、横向滚动、行号（>3 行时）、复制按钮；KaTeX 公式行内与块级均要正确；链接点击走系统浏览器前二次确认（外链）。

### 3.3 工具调用卡片

```
┌────────────────────────────────────────────┐
│ [图标] 工具名 · 状态徽标            耗时 1.2s │
│ 参数摘要（单行省略，可展开完整参数）           │
│ ─ 结果（默认折叠，失败时默认展开）             │
│ ─ 错误（红底 + 错误码 + 建议）                │
└────────────────────────────────────────────┘
```

| 状态 | 徽标 | 说明 |
|---|---|---|
| 等待 | 灰 | 排队中 |
| 运行 | 蓝 + 动效 | 进行中（长任务显示已用时） |
| 成功 | 绿 | 可折叠结果 |
| 失败 | 红 | 默认展开错误 |
| 被拒 | 橙 | 用户拒绝，显示拒绝原因 |

**大输出策略**：结果 > 8 KB 时只显示首 2 KB + 「查看完整输出」（打开全屏文本视图，支持搜索与复制），避免长会话卡顿。

### 3.4 审批卡（P0 核心）

```
┌────────────────────────────────────────────┐
│ ⚠ 需要你的批准                    剩余时间…  │
│ 动作：<动作名/命令摘要>                       │
│ 影响：<一句话说明影响范围>                    │
│ ▸ 查看原始请求（可展开完整载荷）               │
│ [拒绝]        [仅本次允许]        [按策略允许] │
└────────────────────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 三选语义 | 与 Host 侧审批语义一一对应；**不做「默认允许」的隐式行为** |
| 危险动作 | 涉及删除/外发/凭据的操作，主按钮改为**拒绝**（视觉权重反转），并显示风险等级 |
| 拒绝 | 必须可附理由（可选文本框），理由回传 Host |
| 可达性 | 同一审批在三处可达：会话轨迹内、待决聚合页、系统通知直达 |
| 时效 | 显示等待时长；超时/已被其他端处理时卡片置为「已由其他端处理」而非静默消失 |

### 3.5 提问卡（`ask_user`）

| 元素 | 规格 |
|---|---|
| 单选 | 选项列表，单选即提交（可配置需确认） |
| 多选 | 复选 + 「提交」 |
| 自由文本 | 多行输入 + 发送 |
| 混合 | 选项 + 「其他（自定义）」入口 |
| 描述 | 选项下方可有说明文字（来自 Host） |

### 3.6 输入区（Composer）

| 元素 | 规格 |
|---|---|
| 多行输入 | 自动增高（1–8 行），超过滚动；`Shift/Ctrl+Enter` 换行，`Enter` 发送（可在设置中反转） |
| 附件 | 图片（相册/相机/粘贴）、文件（文件管理/分享）、拖拽（2in1/平板） |
| @ 引用 | 工作区 / 文件 / 技能 / 会话引用；输入 `@` 弹层，可键盘导航 |
| / 命令 | 斜杠命令弹层，与 Host 侧命令集一致；显示命令说明与参数提示 |
| 模型与推理强度 | 当前值以 chip 显示，点击切换（窄屏收进「+」菜单） |
| 发送 / 停止 | 运行中发送键变为**停止**（长按可「停止并追加」） |
| 草稿 | 按会话持久化；切换会话/杀进程后仍在 |
| 离线 | 输入可用，发送时入待发队列并明确提示「将在连接恢复后发送」 |
| 键盘避让 | 软键盘弹出时输入区贴键盘上方，轨迹自动滚到底部；避免遮挡最后一条消息 |

### 3.7 待决聚合页

- 按 **紧急度**（危险动作 > 普通审批 > 提问 > 完成通知）与 **时间** 排序；
- 每条一行：会话标题 · 类型 · 动作摘要 · 等待时长；
- 支持**就地处理**（不进入会话即可答复）与「进入会话处理」；
- 全空态文案：「没有待处理事项」。

## 4. 状态与文案规范

| 场景 | 呈现 |
|---|---|
| 未配对 | 首屏配对引导（扫码 / 输入地址 / 自动发现），含「为什么需要配对」一句说明 |
| 连接中 | 顶部细进度条 + 可展开的「正在连接 <Host 名>…」 |
| 已断连 | 顶部横幅：「已断开，正在重试（第 N 次）」+「手动重连」+「查看诊断」 |
| 重连成功 | 横幅消失 + 一条「已恢复连接，正在同步…」短暂提示 |
| 认证失效 | 全屏引导：「需要重新授权」+「重新授权」按钮 + 原因说明（不复用泛化错误） |
| 无会话（空态） | 引导创建首个会话 + 「选择工作区」按钮 |
| 连接成功但无工作区 | 提示添加工作区，并说明它会成为 agent 的工作目录 |
| Host 版本不在矩阵内 | 顶部常驻条纹提示「Host 版本 X 未经验证」，附「仍要继续」/「查看详情」 |
| 能力缺失（如 Host 未启用终端） | 对应入口置灰 + tooltip 说明原因（不隐藏，避免用户困惑） |

**文案纪律**：错误文案必须包含「发生了什么 + 可以做什么」；禁止裸抛技术栈信息（如 `HTTP 403`）作为唯一说明。

### 5.1 2in1 / 平板（外接键盘）

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + N` | 新建会话 |
| `Ctrl/Cmd + K` | 全局搜索 / 命令面板 |
| `Ctrl/Cmd + F` | 会话内搜索 |
| `Ctrl/Cmd + B` | 切换左导航栏 |
| `Ctrl/Cmd + J` | 切换详情栏 |
| `Ctrl/Cmd + Shift + P` | 待决聚合 |
| `Enter` / `Shift+Enter` | 发送 / 换行（可反转） |
| `Esc` | 停止当前轮次（弹二次确认）/ 关闭弹层 |
| `Alt + ↑/↓` | 上一条 / 下一条消息 |
| `Ctrl/Cmd + Shift + C` | 复制选中代码块（带语言标记） |
| `Ctrl/Cmd + ,` | 打开设置 |
| `F5` | 手动重连 |

### 5.2 手势

| 手势 | 行为 |
|---|---|
| 右滑（手机，距左缘 20vp 内） | 返回上一级 |
| 长按消息 | 复制 / 引用 / 重发 / 分享 |
| 长按审批卡 | 快速拒绝（需二次确认） |
| 双击标题栏（2in1） | 最大化/还原 |
| 拖拽文件到输入区/工作区 | 添加附件 / 导入文件（目标高亮） |
| 下拉（列表顶部） | 刷新会话列表 |

## 6. 通知规范

| 类型 | 优先级 | 标题 | 正文 | 点击 |
|---|---|---|---|---|
| 审批请求 | 高（响铃/震动，可绕过静默时段，默认关） | `需要批准` | `<会话标题>：<动作摘要>` | 直达审批卡 |
| 用户提问 | 高 | `有问题需要你回答` | `<会话标题>：<问题前 40 字>` | 直达提问卡 |
| 轮次完成 | 普通 | `回答完成` | `<会话标题>` | 直达会话底部 |
| 任务/目标完成 | 普通 | `任务完成` | `<会话标题>：<目标摘要>` | 直达目标区块 |
| 失败/中断 | 普通（红） | `运行失败` | `<会话标题>：<错误码>` | 直达错误位置 |
| 连接断开（可选） | 低（静默） | `连接已断开` | `<Host 名>` | 直达诊断页 |

**内容纪律**：通知正文**不得**包含代码内容、文件内容、凭据；只包含会话标题与动作摘要。锁屏预览按系统设置遵循。

**通知去重**：同一审批/提问的多端处理只推一次；处理完成后**主动撤回**对应通知。

## 7. 无障碍规范

| 项 | 要求 |
|---|---|
| 朗读标签 | 每条消息提供可朗读文本：角色 + 内容摘要（长文本截断 + 「共 N 字」）；审批卡朗读「需要批准，动作 X，影响 Y，三个按钮」 |
| 焦点顺序 | 轨迹 → 输入区 → 工具栏；模态弹层焦点锁定在弹层内 |
| 动态字号 | 支持系统字号 100%/150%/200%；200% 下不截断关键按钮（允许换行/折叠） |
| 对比度 | 正文与背景 ≥ 4.5:1；状态徽标 ≥ 3:1 |
| 动效 | 尊重「减弱动效」系统设置；流式光标动效可关闭 |
| 色彩不唯一 | 工具状态不能只用颜色区分，必须带文字/图标 |
| 纯朗读路径 | 读消息、批审批、发消息三条核心路径可纯朗读完成（M8 验收项） |

## 8. 视觉与主题

| 项 | 规格 |
|---|---|
| 主题模式 | 跟随系统 / 浅色 / 深色（设置可覆盖） |
| 品牌色 | 与 dsh 品牌一致的主色；端侧定义 token 表（背景/表面/边框/文本三级/主色/语义色） |
| 代码高亮 | 与 Web 端**同源主题**（抽样验收：同一段代码在两端色彩语义一致） |
| 字号体系 | 标题 20/18/16、正文 16（可缩放）、次要 14、说明 12 |
| 圆角与间距 | 统一 token：圆角 8/12/16，间距 4 的倍数 |
| 动效时长 | 常规 200 ms，页面切换 250 ms，弹层 150 ms |
| 图标 | 系统符号优先；自定义图标统一线宽 |

## 9. 性能体感指标（体验向，验收口径）

| 场景 | 目标 |
|---|---|
| 冷启动到可交互 | ≤ 1.5 s（P50） |
| 列表滑动 | ≥ 55 fps（1000 项） |
| 会话切换 | ≤ 200 ms 显示首屏内容 |
| 流式增量呈现 | ≤ 150 ms 可见延迟 |
| 长会话滚动 | ≥ 55 fps（500+ 事件） |
| 折叠态切换 | 无可见白屏，重排 ≤ 1 帧 |
| 通知点击到卡片可操作 | ≤ 800 ms |
| 内存 | ≤ 150 MB（典型会话），> 250 MB 触发告警日志 |

# HDSH 品牌资源

本目录的图片**全部由脚本生成**，不要手工替换：

```bash
node tools/make-brand-assets.mjs           # 生成全部尺寸
node tools/make-brand-assets.mjs --probe   # 只做几何数值校验，不写文件
```

| 文件 | 用途 | 尺寸 |
|---|---|---|
| `hdsh-icon.png` | README / 商店之外的展示图（带圆角，看起来就是一个应用图标） | 512 |
| `hdsh-mark.png` | 纯标记、透明底（做浅色背景物料时用） | 256 |

应用图标本体不在这里，而是直接写进 HarmonyOS 的资源目录：

| 路径 | 说明 |
|---|---|
| `AppScope/resources/base/media/{background,foreground}.png` | 分层图标的两层（系统自己加遮罩） |
| `entry/src/main/resources/base/media/{background,foreground}.png` | 同上；**必须与 AppScope 完全一致**，否则不同入口显示不同图标 |
| `entry/src/main/resources/base/media/startIcon.png` | 启动窗口图标（144，系统回退用） |

## 设计

**参考官方但刻意不同**。DeepSeek 的品牌符号是**鲸鱼**，主色是偏亮的蓝；本图标：

1. **构图**：以字母 **H**（HDSH）为主体——是**字形标记**，不是插画；
2. **语义**：横杠做成一道**斜向开口的链环**（carabiner）。产品名 `harness` 本义就是
   "挂具/绳结"，而客户端做的事正是"挂接到 Host"。斜切而不是正切，是因为
   图标在 48px 下只剩几像素：正切读起来像"横杠断了"（像渲染缺陷），斜切读起来像"互相勾住"；
3. **血缘**：H 的下腔内放三道**同心波纹**（海的暗示）——与鲸鱼同源，但不是任何生物形象；
4. **配色**：深靛紫 `#2B2E8F` → 青绿 `#0FB5A0` 的对角渐变，加左上柔光。
   与官方偏亮的蓝属于不同色相区间，并排不会被误认成同一个图标。

## 为什么形状是代码

1. **可复现**：六个尺寸/形态（1024 两层、144 启动图、512 展示图、256 纯标记）。
   手工导出必然出现"改了其中三个、忘了另外三个"，而图标不一致在桌面、任务卡片、
   关于页同时出现时非常显眼；
2. **可审阅**：圆角半径、弧的圆心与半径都是代码，能 diff、能讨论；二进制 PNG 不能；
3. **零依赖**：只用 Node 内置 `zlib` 写 PNG，不引入需要本地编译的图形库。

## 两条踩过的坑（留档）

1. **`fill` 只加墨、不减墨**。第一版把链环的开口开在右端、且位于腿的 x 范围内，
   而腿是**先画的**——于是开口在环的形状里存在、在像素上却被腿糊掉了。
   教训：想让"减法"生效，要么把它放进同一个 SDF（如本版把开口并进横杠的 SDF），
   要么显式实现擦除；**不能**指望后画的形状去挖掉先画的。
2. **字符画会骗人，数值不会**。开口只有 32px 宽，在 64 列的降采样预览里被平均掉，
   看起来"开口没生效"。真正定案的是 SDF 数值：开口中心 `sdf=+16`（在形状外）、
   两侧 `sdf=-46`（在形状内）。字符画只用来校验构图，不用来定案。
